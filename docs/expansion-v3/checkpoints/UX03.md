# UX03 — Linux visual review

Linux player built with Unity 6000.3.28f1 and screenshots captured at 1440×900. `docs/validation/hackathon-normal-1440.png`, `hackathon-build-1440.png`, `hackathon-systems-1440.png` and `hackathon-settings-1440.png` show the actual rendered player. Review caught overlapping camera hint/controls and excessive settings spacing; those were corrected. The build view shows the grid, ghost failure reason and catalog; starter solar is centered on its reserved cell. Labels on crew and airlock still overlap in the 3D view, and the build catalog type is small at this resolution. These are remaining presentation limitations, not evidence of a photorealistic or complete visual redesign.

PlayMode 36/36 including the build/assign flow, terrain occlusion, mixer state and source cleanup: `docs/validation/hackathon-playmode.xml`. The final settings layout change was compiled into the player after that full run. No actual audio listening was performed. Pointer UI/drag filtering is implemented but not yet backed by an end-to-end simulated pointer drag test.
